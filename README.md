# Healthcare Patient Analytics SQL

A practical SQL project focused on analyzing healthcare patient data.

## Project Objective

The objective of this project is to use SQL to explore and analyze healthcare patient data and answer practical analytical questions related to:

* Patient demographics
* Hospital departments
* Diagnoses
* Length of stay
* Healthcare costs

## Tools

* SQL
* GitHub
